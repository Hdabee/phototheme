# PhotoTheme V5 — Prévisualisations et effets visuels des thèmes

## Pourquoi cette version

Les thèmes ne se distinguaient pas assez à l'écran. Cette extension apporte :

- des cartes de prévisualisation visuellement différentes ;
- un aperçu grand format du thème choisi ;
- des effets de rendu vraiment distincts : papier patrimonial, galerie minimaliste, Polaroids superposés, planche contact noir et blanc ;
- des cadres, textures, ombres, perforations et traitements d'image propres à chaque thème.

## Installation

Placez `install_phototheme_v5_theme_previews_and_effects.py` dans le dossier parent de `phototheme-python-starter` puis lancez :

```powershell
py .\install_phototheme_v5_theme_previews_and_effects.py
```

Ensuite :

```powershell
cd .\phototheme-python-starter
.\start.ps1
```

Rechargez `http://127.0.0.1:8000` avec `Ctrl + F5`.

## Validation

```powershell
.\test.ps1
```

# PhotoTheme V7 — Atelier

## Installation

Placez `install_phototheme_v7_atelier.py` dans le dossier parent de `phototheme-python-starter`, puis lancez :

```powershell
py .\install_phototheme_v7_atelier.py
```

Puis :

```powershell
cd .\phototheme-python-starter
.\start.ps1
```

Rechargez `http://127.0.0.1:8000` avec `Ctrl + F5`.

## Nouveaux thèmes Atelier

### Reconstructed Portrait

Utilisez 4 images : trois archives et une photo récente. Cliquez sur la photo récente puis `Définir comme photo héro`. Renseignez le panneau Histoire, puis choisissez `Reconstructed Portrait` et `Atelier · Récit 4 images`.

### Island Poster

Utilisez 3 ou 4 images. Choisissez votre image principale comme photo héro, renseignez titre, lieu et période, puis choisissez `Island Poster` avec une composition Atelier.

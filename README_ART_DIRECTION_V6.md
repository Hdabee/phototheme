# PhotoTheme V6 — Art direction et thème rétro

## Installation

Placez `install_phototheme_v6_art_direction_themes.py` dans le dossier parent de `phototheme-python-starter`, puis lancez :

```powershell
py .\install_phototheme_v6_art_direction_themes.py
```

Puis :

```powershell
cd .\phototheme-python-starter
.\start.ps1
```

Ouvrez `http://127.0.0.1:8000` et faites `Ctrl + F5`.

## Thèmes

- Archive Vivante : récit personnel, photos anciennes et photo actuelle héroïque.
- Éditorial Magazine : couverture graphique et titrage fort.
- Scrapbook Authentique : papier, ruban, tirages superposés.
- Contact Sheet Archive : rouleau de film, numéros, noir et blanc.
- Rétro Sunshine : carte souvenir seventies, soleil graphique, palette orange, jaune et brun.

## Utilisation recommandée

Pour votre frise : importez les trois portraits découpés et une photo récente, ajoutez les légendes, choisissez `Archive Vivante`, puis `Story · 4 images`.

Pour tester le rétro : choisissez `Rétro Sunshine` avec trois ou quatre photos de voyage, famille ou vacances.

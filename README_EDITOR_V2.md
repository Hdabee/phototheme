# PhotoTheme Web V2 — Editeur photo

## Installation

Placez `install_phototheme_web_v2_editor.py` dans le dossier parent de `phototheme-python-starter`, puis lancez :

```powershell
py .\install_phototheme_web_v2_editor.py
```

Ensuite, dans le projet :

```powershell
.\start.ps1
```

Ouvrez `http://127.0.0.1:8000`.

## Fonctions

- edition individuelle non destructive ;
- affichage complet ou remplissage de la cellule ;
- rotations par 90 degres ;
- miroir horizontal ;
- luminosite, contraste, saturation et nettete ;
- reinitialisation ;
- themes enrichis ;
- collage PNG avec les reglages appliques.

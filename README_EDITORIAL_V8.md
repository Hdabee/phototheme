# PhotoTheme V8 — Editorial Quality

## Objectif

Cette version remplace les compositions chargées du thème Atelier par une timeline éditoriale stricte : aucune superposition accidentelle, zones réservées pour les textes, trois archives alignées et une photo récente mise en avant.

## Installation

Placez `install_phototheme_v8_editorial_quality.py` dans le dossier parent de `phototheme-python-starter` puis lancez :

```powershell
py .\install_phototheme_v8_editorial_quality.py
```

Puis :

```powershell
cd .\phototheme-python-starter
.\start.ps1
```

Rechargez `http://127.0.0.1:8000` avec `Ctrl + F5`.

## Usage recommandé

1. Importez 4 photos.
2. Identifiez vos trois archives et votre photo récente.
3. Sélectionnez la photo récente et cliquez sur `Définir comme photo récente`.
4. Ajoutez les légendes : Enfance, Jeune adulte, Portrait, Aujourd'hui.
5. Remplissez titre, sous-titre, chapitre et période.
6. Choisissez `Portrait Timeline Editorial`.
7. Cliquez `Créer mon collage PNG`.

## Variante

`Editorial Night` utilise la même composition avec un fond graphite et un contraste plus photographique.

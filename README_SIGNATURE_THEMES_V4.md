# PhotoTheme V4 — 4 thèmes signatures

## Installation

Placez `install_phototheme_v4_signature_themes.py` dans le dossier parent de `phototheme-python-starter`, puis lancez :

```powershell
py .\install_phototheme_v4_signature_themes.py
```

Ensuite :

```powershell
cd .\phototheme-python-starter
.\start.ps1
```

Ouvrez `http://127.0.0.1:8000`, puis faites `Ctrl + F5`.

## Thèmes

- Heritage Timeline : 3 ou 4 photos, frise avec légendes.
- Minimal Gallery : 3 ou 4 photos, une image principale et des images secondaires.
- Polaroid Memory : 3 ou 4 photos, cadres superposés et légères rotations.
- Film Contact Sheet : 4 ou 6 photos, perforations et numérotation.
